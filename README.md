# Oakland Tech Chess Club Website

Official multi-page website for the **Oakland Technical High School Chess Club**.

## GitHub Repository & Live Page Setup
1. Public Repository Name: `oakland-tech-chess-club`
2. Live GitHub Pages Link: `https://<your-username>.github.io/oakland-tech-chess-club/`

## Files Included
- `index.html` — Home page introducing the club, Friday lunch schedule, and "Why Join Our Club?" highlights.
- `about.html` — Club mission, activities, leadership team, Hera design/theory collaboration, and match highlights.
- `resources.html` — Annotated opening & tactical chessboard diagrams, study guides, and Lichess / Chess.com links.
- `join.html` — Friday lunch schedule (Room 214), membership requirements, registration button, and contacts.
- `styles.css` — Custom black, light purple, gold, and toned hardwood neo-matrix stylesheet attached to every page.
